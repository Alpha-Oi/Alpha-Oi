#### 📌 Задача

Действующий магазин на Ozon терял маржу из-за ручного управления ценами, несистемных поставок и отсутствия юнит-экономики по SKU. Собственник хотел автономную платформу, которая **сама держит цены в безопасном коридоре**, планирует поставки FBO/FBS и даёт ежедневную сводку по бизнесу — **без найма дополнительных сотрудников**.

#### 💡 Решение

AI-платформа, которая закрывает полный цикл операционки магазина: от синхронизации каталога до голосового управления через Telegram. Построена на принципе **«работает без единого стороннего ключа»** — все внешние провайдеры (LLM, распознавание речи, тренды) спрятаны за интерфейсом с рабочими заглушками и включаются одной переменной `.env`.

#### 🎯 Ключевые бизнес-результаты

| Результат | Как достигается |
|---|---|
| 📉 **Защита маржи** | Репрайсер с полом цены, коридором и стоп-краном. SKU без себестоимости не трогаются автоматически |
| ⚙️ **Экономия времени** | Автоматические ночные бэкапы, плановые синхронизации, авто-ответы на отзывы и вопросы |
| 📊 **Прозрачная экономика** | Юнит-экономика по каждому SKU: себестоимость (файл или HTTP-источник: 1С, МойСклад) × комиссия Ozon × логистика |
| 🚀 **Рост конверсии** | A/B-тесты главных фото карточек с автоматическим выбором победителя |
| 🗣️ **Управление голосом** | Telegram-бот с распознаванием речи (Whisper): можно спросить «что по продажам вчера?» |
| 🔐 **Безопасность** | Ключи Ozon и секреты — под Fernet-шифрованием. В логи попадает только маска |

#### 🧩 Что внутри платформы

```text
Каталог и цены       →  Синхронизация с Ozon Seller API
Юнит-экономика       →  Себестоимость (файл / 1С / МойСклад) + комиссии
Репрайсер            →  Пол цены · коридор · стоп-кран · логика по SKU
Поставки FBO/FBS     →  Планирование и синхронизация складов
A/B-тесты фото       →  Эксперименты с главной карточкой
Тренды спроса        →  ozon (без ключа) + внешние + публичные источники
AI-инструменты       →  Описания · ответы на отзывы · утренняя сводка
Голосовое управление →  Telegram-бот + Whisper
Автоматизации        →  Планировщик задач (worker) с ночными бэкапами
